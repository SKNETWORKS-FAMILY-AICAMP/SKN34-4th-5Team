## 포함한 변경

- 공개 FOOD 분류 안에서도 외부 식당, 내부 먹거리, 술집을 구분한다. 일반 식당 교체는 외부 식당을 대상으로 하며 STATION은 내부 간식으로 보존한다. 일반 카페와 내부 카페도 구분한다.
- 돈카츠·돈까스·돈가스 및 나머지 일정 보존 문구를 처리하고, 검색 결과에 무관한 식당만 있으면 제한된 표기 변형 후보를 이어서 조회한다. 검색어 자체를 메뉴 판매 근거로 쓰지 않는다.
- 외부 술집은 같은 지점의 실제 평점과 평가 수 1건 이상이 확인된 경우에만 후보에 넣는다. 식당·카페의 기존 추천 정책과 자리어때 내부 매장의 평점 면제를 유지한다.
- Docker 재시작 후 숙박 브라우저가 임시 PID/소켓 때문에 시작하지 못하는 문제에 `/tmp` tmpfs와 상태 검사를 적용한다.
- 코스 평가 초안 20종, 방문 역할·메뉴 교체 계약 17종, 무료 CI 연결과 기존 검증 기록을 함께 보존한다. 평가 초안의 미실행 값을 실제 성능 결과로 표시하지 않는다.
- 최신 팀 변경의 불명확 질문 처리, 공동 홈구장 티켓 안내, 시설 질문 가드, chat_eval 회귀를 유지한다. CI 검사 목록 충돌은 양쪽 테스트를 모두 포함하도록 정리했고 nginx는 팀 변경을 기준으로 통합했다.
