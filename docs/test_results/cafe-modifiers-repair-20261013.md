## 결론과 정책

로컬 실패는 ‘조용한’을 해석하지 못해서가 아니었다. 장소 후보는 확보했지만 SQL 조건 근거가 비어 있었고, 신규 웹 검색이 꺼진 환경에서 기존 매장 프로필의 후기를 조건 검사에 연결하지 못했다. 여기에 최근 180일·독립 후기 2건 조건과 가까운 후보군에 몰린 조회 예산이 추가 탈락을 만들었다.

사용자 요청으로 조용함·넓음·좋은 분위기는 같은 매장의 실제 이용 후기 1건으로 추천한다. 코스 후기 조건의 일괄 180일 제한도 제거했다. 출처 링크를 붙이고 이 특성 때문에 별도 한계 문구를 붙이지 않는다. 광고·다른 지점·미래 날짜·실제 본문에 없는 인용·상충 내용은 통과시키지 않는다. 콘센트·주차의 근거 건수와 술집 평점·내부 먹거리 출처 정책은 유지한다.
